LSAT Miss Capture

Sends the questions you missed (and the ones you got right but flagged or changed in blind review) to the Inbox tab of your journal sheet. It stores no question text.

1 Site access

Firefox lets you choose which sites an add-on can read. This one needs:

    Some access is missing, so captures cannot run there. Click the button, then choose Allow in the Firefox prompt.

    If the prompt does not appear: open about:addons → LSAT Miss Capture → Permissions, and switch each site on.

    ✓ All set.

    2 Connect your sheet

    Deploy the Apps Script as a web app (README → Deploy the web app), then paste its URL and the secret from Script Properties.

    Stored only in this browser (browser.storage.local). Leave blank to keep the saved one.

    Parses results pages and shows what would be sent, below and in the popup, without writing to the sheet. It may still read your Lists and Mapping tabs so the preview shows final values.
